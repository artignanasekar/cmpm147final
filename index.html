Mission Brief

Enter a procedurally generated sector, scan planets, recover relics, survive environmental hazards, and return to the jump gate.

Controls

Move: Arrow keys or WASD

New run: R

Procedural Systems

Each run generates a new region map, planet layout, hazard layout, and pattern lattice. The pattern lattice changes tile behavior and influences danger, repairs, and fuel bonuses.

Midterm Tool Integration

This game uses my own space generator ideas for sectors and planets, and it integrates the outside Pattern Generator tool by turning shape-based grid patterns into a live gameplay system that affects each run.
